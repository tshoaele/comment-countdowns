# Comment Countdowns

A minimal, military-styled tracker for daily comments across **X, Threads, Pinterest, Facebook, TikTok, and Other**. Each platform counts down from **20**, and every log is date-stamped in a persistent history.

## Features
- Per-platform countdown from 20 (independent goals)
- Date-stamped log history showing what was logged on which day
- Data stored locally in your browser (`localStorage`)
- Auto-saves at midnight; resets today with one click
- Dark blue / military aesthetic with subtle grid animation

## Live demo
Once GitHub Pages is enabled, your app will be available at:
`https://<your-username>.github.io/<repo-name>/`

## Run locally
Just open `index.html` in any modern browser — no build step, no dependencies.

## Deployment (GitHub Pages)
1. Create a new repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and this `README.md`.
3. Go to **Settings → Pages**.
4. Under **Source**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then **Save**.
6. Wait ~1 minute, then visit `https://<your-username>.github.io/<repo-name>/`.
